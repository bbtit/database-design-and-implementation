# 第1章 Database Systems（データベースシステムとは何か）

## なぜDBMSが必要か

データベースはレコードの集まりで、それを管理するソフトウェアがデータベースシステム。ファイルに保存するだけでは足りない理由は、次の要件を満たす必要があるから。

- 大量のデータを、遅い永続ストレージ（ディスク）に置いて扱う
- 複数ユーザーが同時に共有して使う
- SQLのような高水準のインタフェースを提供する
- 同時更新やクラッシュが起きてもデータを正しく保つ

## エンジンとアプリケーション

- データを保持するのが**データベースエンジン**。入出力を担当してエンジンを呼び出すのが**アプリケーション**。
- 接続方法は2種類。
  - **埋め込み型**：1つのプログラムがエンジンを独占する（SQLiteのようなもの）
  - **サーバー型**：複数のクライアントが1つのエンジンを共有する

## Derby と SimpleDB

- Derby は SQL をほぼフル実装した本格的なDB。SimpleDB は教育用で、コードが読みやすい。本書は第3章から SimpleDB を実装していく。
- SimpleDB の SQL は最小限のサブセット。
  - `select-from-where` のみ。WHERE は **AND で結んだ等値比較だけ**
  - 使えないもの：`*`、AS／別名、NULL、JOIN句、ORDER BY／GROUP BY、集約、サブクエリ、UNION、演算子
  - INSERT は値の直接指定のみ。UPDATE の SET は1項目だけ
  - エイリアスがないので、フィールド名は全テーブルで重複させない
